# TRACEWISE — تريس وايز

> **افهم المشكلة. اعثر على السبب. تحقّق من الحل.**

مساعد المبرمج الذكي — تطبيق موبايل حقيقي (React Native / Expo) يحوّل كل مشكلة برمجية إلى **Debug Case** مستقلة تمر بمسار هندسي كامل:

```
المشكلة ← جمع الأدلة ← تحليل الأدلة ← الاحتمالات ← السبب الجذري ← خطة الإصلاح ← تطبيق الإصلاح ← التحقق ← حفظ المعرفة
```

## لماذا TRACEWISE ليس chatbot؟

- **لا قرار بدون دليل**: التحقق من الحل يتطلب دليلًا جديدًا يناقض إشارة الفشل (مثل `HTTP 401 → HTTP 200`)، وإلا تبقى الحالة «مرجح الحل» فقط.
- **القواعد المحلية أولًا**: محرك تشخيص محلي (15+ قاعدة) يعمل **بدون إنترنت** تمامًا. الذكاء الاصطناعي اختياري، ويُستدعى بعد القواعد المحلية وبعد حجب الأسرار، ولا يقرر التحقق أبدًا.
- **لا سر يُخزَّن**: حجب تلقائي (Redaction) للـ Tokens وJWT وكلمات المرور ومفاتيح API وبيانات قواعد البيانات قبل التخزين أو أي إرسال.
- **لا كتابة على GitHub بدون موافقتك**: التكامل قراءة فقط، وأي عملية كتابة تمر بدورة: **اقتراح ← موافقة ← تنفيذ**.

## الشاشات

| الشاشة | الوصف |
|---|---|
| البداية | الشعار + تحميل أنيق |
| التعريف | 3 صفحات: ماذا يفعل / كيف يساعد / كيف يحمي |
| الرئيسية | ترحيب، إحصاءات، آخر الحالات، إجراءات سريعة |
| مشكلة جديدة | معالج 4 خطوات (أساسيات ← خطأ ← سياق ← مراجعة) |
| تفاصيل المشكلة | 5 تبويبات: الرحلة / الأدلة / التحليل / الخطة / التحقق |
| Scanner | لقطة شاشة + استخراج الإشارات (رسالة خطأ، ملف، سطر، Stack، حزمة) — كله قابل للتعديل |
| السجل | بحث + تصفية بالحالة/الخطورة/اللغة |
| ذاكرة المبرمج | أسباب متكررة، حلول ناجحة، حالات مشابهة، بصمة لكل مشكلة |
| مركز الأمان | ما يخرج من الجهاز، الأسرار المحجوبة، الصلاحيات، سجل الأمان، فحص الآن |
| التكاملات | GitHub (قراءة فقط) مع سياسة كتابة صارمة |
| الإعدادات | لغة (عربي/إنجليزي)، وضع ليلي، خصوصية، AI، تصدير/استيراد |

## حالات المشكلة

`مفتوحة ← قيد التحليل ← خطة إصلاح ← مرجح الحل ← تم التحقق ← مغلقة`

آلة حالات قانونية فقط — مع مسار انتكاسة (`مرجح الحل ← خطة إصلاح`) وإعادة فتح.

## البنية (Clean Architecture)

```
src/
├── domain/        # الأنواع، آلة الحالات، الخطورة، البصمة (نقية 100%)
├── diagnosis/     # قاعدة القواعد المحلية + محرك التشخيص
├── verification/  # محرك التحقق (الدليل يقرر، لا AI)
├── security/      # Redaction + Scanner (استخراج الإشارات)
├── ai/            # بوابة AI اختيارية (متوافقة مع OpenAI)
├── integrations/  # GitHub Client (READ ONLY + اقتراح/موافقة/تنفيذ)
├── storage/       # AsyncStorage + SecureStore + حالات تجريبية
├── state/         # AppStore (Context + أفعال دورة الحياة)
├── core/          # i18n (ar/en) + Theme (RTL حقيقي)
├── ui/            # نظام التصميم (بطاقات، أزرار، شارات…)
└── features/      # الشاشات
```

## التشغيل

```bash
npm install
npx expo start            # ثم امسح QR بـ Expo Go (Android/iOS)
npm run web               # نسخة ويب
```

## الاختبارات

```bash
npm test        # 66 اختبارًا (Jest + jest-expo + Testing Library)
npm run typecheck
```

تغطي الاختبارات: **Redaction، Diagnosis، Severity، Case State Machine، Verification، Problem Fingerprint، Scanner**، بالإضافة إلى اختبارات واجهة (Widget Tests) للرئيسية ومعالج إنشاء المشكلة وتفاصيل الحالة.

## مبادئ الأمان

1. حجب الأسرار دائمًا مفعّل — لا يمكن إيقافه.
2. الأسرار تُحفظ فقط في SecureStore (مفاتيح GitHub/AI) ولا تظهر في السجلات.
3. مركز الأمان يعرض كل اتصال خارجي محتمل.
4. إرسال البيانات للذكاء الاصطناعي يتطلب تفعيلًا + موافقة صريحة + حجبًا مسبقًا.
